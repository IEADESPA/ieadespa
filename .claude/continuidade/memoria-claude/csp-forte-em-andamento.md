**Armadilhas que custaram achado (valem para qualquer CSP/mudança parecida):** (1) o `connect-src 'self'` estrito vale TAMBÉM para o fetch() do service worker (recusava as fontes do Google; a página não vê, só o console do SW) → SW ignora outra origem; (2) o JSON dos argumentos preserva TEXTO: onde o código do atributo antigo virava literal (número), um valor lido de `.value` precisa de `Number()` (teste `frontTipoDosArgumentos.test.js`); (3) teste que fixa "v4" do cache quebra ao subir versão; (4) em Git Bash `$TEMP` = `/tmp/…`; `git worktree add` falha se a pasta foi apagada com `rm -rf` sem `git worktree prune`/`remove`, e os comandos seguintes rodam na pasta ERRADA — encadear com `&&` e conferir `pwd`/ramo antes de `git push`; (5) `sleep` em primeiro plano é bloqueado.
