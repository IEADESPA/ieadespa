# Instruções para agentes (Codex e outros)

Antes de qualquer tarefa neste repositório:

1. Leia o [`CLAUDE.md`](CLAUDE.md): as regras obrigatórias (toda alteração vai para o GitHub na hora, segredo nunca em
   texto puro, protótipos antigos só para consulta).
2. Leia o `HANDOFF.md` da raiz, se existir: o estado do trabalho e o próximo passo exato. Ele é de cada computador e fica
   fora do Git (está no `.gitignore`).
3. Consulte o servidor MCP `memoria-projeto` (`search_nodes` ou `read_graph`), se estiver configurado neste computador:
   os fatos duráveis do projeto (arquitetura, regras de negócio, decisões do responsável, pendências). Para instalar,
   siga o [`.claude/continuidade/LEIA-ME.md`](.claude/continuidade/LEIA-ME.md).
4. Confira `git status` e o ramo atual.

O contexto completo do sistema está no [`README.md`](README.md) e nos planos em [`docs/plano/`](docs/plano/).
Tudo em português do Brasil.
